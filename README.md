# **UI Blocker Pro — Chrome & Firefox Extension**

**Customize your browsing experience with element opacity control**

## 🌟 Overview

**UI Blocker** is a powerful and user-friendly cross-browser extension for Chrome and Firefox that allows you to reduce distractions and take control of your browsing environment. Whether you're watching videos, reviewing image-heavy content, or working with cluttered interfaces, UI Blocker lets you customize the opacity of images, videos, and specific elements on any website.

---

## ⚙️ Features

* **Opacity Settings** for images and videos
* **Custom CSS Selectors** to apply opacity to specific elements
* **Domain Configuration** to apply rules only to selected websites
* **Live Update Filters** and persistent settings

---

## 🧭 Getting Started

### 1. **Install the Extension**

* **Chrome**: Add "UI Blocker" via the Chrome Web Store or load the directory as an unpacked extension (`chrome://extensions` → Developer mode → Load unpacked).
* **Firefox**: Install from Firefox Add-ons (AMO), or load temporarily via `about:debugging` → This Firefox → Load Temporary Add-on → select `manifest.json`. Requires Firefox 121+.

---

## 🛠️ User Guide

### 🔹 Opacity Settings

Adjust the opacity levels for **images** and **videos** globally:

* **Image Opacity**: Set the transparency of all `<img>` elements.
* **Video Opacity**: Set the transparency of all `<video>` elements.

Use the sliders to select a percentage (0% = fully transparent, 100% = fully visible).

---

### 🔹 Custom Selectors

Define your own CSS selectors to target specific elements on the page:

* Input CSS selectors in the text area separated by commas (e.g., `.my-class, #my-id, div.special`)
* Adjust the **Custom Selectors Opacity** using the slider.

This lets you control elements like popups, overlays, sidebars, or ads by making them less prominent.

---

### 🔹 Domain Configuration

Target settings to specific websites:

1. Enter a domain (e.g., `example.com`)
2. Click **Add Domain**
3. To remove, click the **Remove** button next to the domain.

Only the specified domains will have the opacity rules applied.

---

## 💾 Save & Apply

* **Update Filters**: Immediately apply the new settings to the current session.
* **Save Settings**: Persist settings across sessions.

---

## 💡 Tips

* Use browser tools (Right-click → Inspect) to find specific classes or IDs of distracting elements.
* Combine selectors for fine-tuned control.
* Adjust opacity instead of blocking elements for a less jarring experience.

---

## 🛑 Note

UI Blocker does **not** block content; it modifies visual prominence via CSS. It is non-invasive and safe for sensitive workflows.
